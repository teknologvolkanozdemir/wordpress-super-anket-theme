# wordpress-super-anket-theme

Ücretsiz, erişilebilirlik odaklı WordPress teması. Anket ve araştırma hizmetleri
sunan siteler için sade bir başlangıç noktasıdır.

## Kurulum

Bu klasörü WordPress kurulumunuzdaki `wp-content/themes/super-anket` dizinine
kopyalayın ve **Görünüm → Temalar** bölümünden **Super Anket** temasını
etkinleştirin. Site adını ve açıklamasını **Ayarlar → Genel** bölümünden,
gezinme menüsünü **Görünüm → Menüler** bölümünden yapılandırabilirsiniz.

## Erişilebilirlik

Tema; ana içeriğe atlama bağlantısı, semantik sayfa bölgeleri, klavye ile
görülebilen odak göstergeleri, okunabilir kontrast, ekran okuyucu metinleri ve
azaltılmış hareket tercihi için destek içerir. Yayınlanan içeriklerin alternatif
metinleri ve erişilebilirliği de site yöneticisi tarafından kontrol edilmelidir.
